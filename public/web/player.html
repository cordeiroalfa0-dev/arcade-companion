CONTROLES · JOGADORES 1 E 2

      

        
Controles USB, Bluetooth, XInput, DirectInput, DualShock e genéricos usam a Gamepad API do navegador. O primeiro controle conectado é atribuído ao Jogador 1; o segundo ao Jogador 2. Controles especiais podem ser remapeados abaixo.

        
Verificando controles conectados…

        

          
          
        

        

        

          
PLAYER 1 · PADRÃOSetas · Z/X/A/S · C crédito · Enter start

          
PLAYER 2 · PADRÃOT/F/G/H · J/K/U/I · V crédito · B start

        

        
Os atalhos usam a posição física das teclas (KeyboardEvent.code), não as letras impressas; funcionam em QWERTY, AZERTY, QWERTZ e ABNT2. Para trocar qualquer botão individualmente, use o remapeador por jogador.

        
        
No remapeador, escolha P1 ou P2, toque em “Set” no botão desejado e pressione uma tecla ou botão do controle. O remapeamento individual salvo prevalece sobre o perfil universal.
